# Shared workspace context

This workspace hosts two independent microservices that are developed in
parallel by multiple AI coding agents.

| Service | Stack | Migrations |
|---|---|---|
| `auth-service` | Spring Boot + Liquibase | `src/main/resources/db/dbchangelog.xml` |
| `payment-service` | Spring Boot + Flyway | `src/main/resources/db/migration/V<n>__*.sql` |

## Rules for agents

1. Database migrations are **sequenced**. Liquibase uses `<changeSet id="N">`,
   Flyway uses `V<N>__name.sql`. Two agents must never claim the same `N`.
2. Never run `git checkout` in this folder while another agent is working.
3. Test ports are allocated per session; read `SP_PORT_BASE` if it is set.
